Split DNS
Domain → nameserver。瀏覽器 Enforce 走 gateway（通常不必密碼）。勾「系統 /etc/resolver」才會寫系統 DNS（要授權）。要用 Touch ID：先執行 sh scripts/enable-touchid-sudo-macos.sh，再按 Reinstall（會開 Terminal 指紋）。
操作說明
  1. 安裝 native host：sh scripts/install-native-host-macos.sh chrome-dev
  2. SSH Host = SOCKS 出口機，不是目標網站
  3. Global：必選 Host，全部流量走 tunnel
  4. Routes：Host 可空白；只開已啟用規則的出口；未匹配預設本機
  5. 未匹配選 Default 時，上方 Host 才會作為兜底出口
  6. Pattern 可寫 example.com 或 example.com/api
  7. Split DNS：依 domain 選 nameserver（本機 stub 127.0.0.1:53535）；與 proxy 獨立
  8. Popup 不穩時用「視窗」或 ⌥⇧W
